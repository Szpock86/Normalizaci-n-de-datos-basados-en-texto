# Normalizacion de datos basados en texto

---

 ## Resumen
 
---

En este mini proyecto se realizó la limpieza y transformación de datos en Excel mediante diferentes funciones de texto. Se utilizaron funciones como ESPACIOS, NOMPROPIO, IZQUIERDA, EXTRAE, CONCAT y MAYUSC.

---

## Funciones Utilizadas

- =ESPACIOS()
- =NOMPROPIO()
- =IZQUIERDA()
- =EXTRAE()
- =CONCAT()
- =EXTRAE()
- =MAYUSC()
